主な機能

商品の登録・編集・削除（店員モード）
バーコードスキャンによる商品追加
現金・電子マネー決済
レシート発行（テキストファイル保存）

使い方

1　admin_barcode.txtに店員バーコードを記入する。
2　起動して店員バーコードをカメラに近づける。
3　商品を登録する（割引しない場合は、0％に設定して下さい）
4　商品をスキャンする。
5　会計方法を選択する。
6　レシートを発行するか選ぶ。

ソースコードではレシート発行時の店名を変更できますがexe版では店名変更はできません。
ソースコード版をご利用ください。
推奨Pythonバージョン
3.12

2次配布する場合は、お問い合わせフォームに2次配布するurlを入力してください。
